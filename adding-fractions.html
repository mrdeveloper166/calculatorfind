Adding fractions calculator and tool


How to use adding fractions tool and how to calculate fractions.

Enter fractions and push the = button.

Enter simple fractions with slash (/) and example given below.

For example: 1/2 + 1/3

Enter mixed numbers with space.

For example: 2 1/2 + 1 1/3

Adding fractions example

1/2 + 1/3 = (1×3+1×2) / (2×3) = 5/6
