What is Root Calculator


A root is a number that is multiplied by itself the root number of times. For example, the square root (root 2) of 16 (16) is 4, as 42 (4 x 4) = 16. The cubed root (root 3) of 27 (3 ,27) is 3, as 33 (3 x 3 x 3) = 27.
